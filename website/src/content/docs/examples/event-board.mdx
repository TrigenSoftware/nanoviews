This example shows a small public event board built with `nanoviews`, `@nanoviews/router`, `@nano_kit/store`, `@nano_kit/query`, `@nano_kit/router`, `@nano_kit/intl` and `@nano_kit/platform-web`.

It covers routed pages with code splitting, URL filters, an in-memory HTTP API, session auth with a cookie, infinite queries, mutations, optimistic updates, entities, page modules with `Head$`, messages in English and Russian, and dependency injection for every store and service.

Demo users: `ada` / `lovelace`, `grace` / `hopper`.

The [Nano Kit tutorial](https://nano-kit.js.org/tutorial/) uses this app as its running project, built with React.
