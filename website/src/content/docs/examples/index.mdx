Use these examples to see Nanoviews in complete applications, alone and with the stores, queries and routing of Nano Kit. Each example includes an embedded playground and a link to the source code.

| Example | Focus |
|---------|-------|
| [Vite Demo](/examples/vite-demo/) | The Vite starter app: element factories, a component and a signal. |
| [Weather App](/examples/weather/) | Queries, a debounced autocomplete, keyed lists and an optional Dependency Injection variant. |
| [CV Generator](/examples/cvapp/) | Routing with a layout, form bindings, mutations, a navigation guard and polymorphic components. |
| [Rick and Morty Encyclopedia](/examples/rick-and-morty/) | Routing, code-split pages, link preloading and paginated data loading. |
| [Event Board](/examples/event-board/) | Dependency injection, infinite queries, auth, optimistic updates, entities, head management and translations. |
