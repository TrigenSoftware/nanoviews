This example shows a CV generator built with `nanoviews`, `@nanoviews/router`, `@nano_kit/store`, `@nano_kit/query` and `@nano_kit/router`.

It is a compact reference for routed screens with a shared layout, cached async data with mutations, form bindings and a small UI kit of components.
