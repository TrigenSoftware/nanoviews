This example shows a small weather app built with `nanoviews`, `@nano_kit/store`, `@nano_kit/query` and `@nano_kit/platform-web`.

Use the **Basic** version for the shortest path through the data flow. Use the **Dependency Injection** version to see how the stores move out of module scope into factories, which the injection context runs when a component asks for them.
